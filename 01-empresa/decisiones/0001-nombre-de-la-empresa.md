# D-0001 — Nombre de la empresa y del repositorio

- **Fecha:** 2026-09-03
- **Estado:** aceptado (nombre de trabajo; validación final pendiente)
- **Quién:** Rubén

## Contexto

Se crea el repositorio para organizar el proyecto de una nueva empresa de construcción
y remodelación en A Coruña. El repositorio recibe un nombre automático (`RINCOCARABOBO`)
que no representa nada. Se necesita un nombre de trabajo para el proyecto y la empresa.

## Decisión

Adoptar como **nombre de trabajo** la marca **RemodelaT Coruña**
(empresa de reformas y remodelación de viviendas en A Coruña).

- Representación técnica para repositorio y dominios: **`RemodelaT-Coruña`** / `remodelatcoruna…`
  (sin espacios ni caracteres especiales).
- El repositorio de GitHub `RINCOCARABOBO` se renombrará a `RemodelaT-Coruña`.

## Alternativas consideradas

- Mantener `RINCOCARABOBO` → descartado: no representa el proyecto.
- Otros nombres comerciales → pendientes de valorar antes del registro.

## Consecuencias y pendientes

- Renombrar el repositorio en GitHub (Settings → General → Repository name).
- **Pendiente** antes de la constitución:
  - Comprobar disponibilidad de la denominación (Registro Mercantil / marca).
  - Comprobar disponibilidad del dominio y usuarios en redes sociales.
  - Decidir la grafía final exacta (guion, espacios, logo) y la forma jurídica.
- Actualizar este registro cuando se confirme el nombre definitivo.
