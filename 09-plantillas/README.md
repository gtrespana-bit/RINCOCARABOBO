# 09 — Plantillas

**Propósito:** plantillas reutilizables para operar la empresa (en Markdown, y más adelante
en formato editable/PDF para entregar a clientes).

## Plantillas previstas (se crean según se necesiten)

| Plantilla | Uso |
|---|---|
| `presupuesto.md` | **Presupuesto para cliente** (estructura por capítulos, condiciones y exclusiones). Base validada con el modelo de costes (`04-finanzas`) |
| `presupuesto-ejemplo-bano.md` | Ejemplo relleno de presupuesto (baño 4,5 m²) para ver el formato en la práctica |
| `contrato-de-obra.md` | Contrato con cliente (ver también `05-legal-y-tramites/contratos`) |
| `ficha-de-obra.md` | Resumen de cada obra: datos, fechas, importes, contactos |
| `seguimiento-de-obra.md` | Control semanal: estado, incidencias, próximos pasos |
| `listado-de-materiales.md` | Compras por obra |
| `encuesta-de-satisfaccion.md` | Opinión del cliente al terminar (para reputación y web) |

## Reglas

- Crear cada plantilla **después de usarla una vez en papel** (o adaptarla de la experiencia
  previa de Rubén): las plantillas que nacen de la práctica real funcionan mejor.
- Cuando una plantilla se consolide, copiarla a `05-legal-y-tramites/contratos` (si es contrato)
  o usarla desde aquí; revisarlas con la gestoría antes de uso comercial.
