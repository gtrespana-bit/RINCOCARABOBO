# 04 — Finanzas

**Propósito:** los números del negocio: plan financiero, gastos, inversión inicial,
presupuestos económicos y (cuando se opere) facturación y contabilidad.

## Documentos previstos (se crean según se necesiten)

| Documento | Contenido |
|---|---|
| `plan-financiero.md` | Inversión inicial, gastos de constitución, equipamiento, tesorería, punto de equilibrio |
| `estructura-de-costes.md` | Costes fijos y variables de una reforma tipo (mano de obra, materiales, % beneficio) |
| `presupuesto-tipo.md` | Partidas estándar de un presupuesto de reforma (base para ofrecer a clientes) |

## Reglas y notas

- Los **presupuestos de obras concretas** (a cliente) se archivan con la obra en
  [`06-obras-y-proyectos`](../06-obras-y-proyectos/README.md); aquí van el plan financiero
  general, las cuentas de la empresa y los gastos.
- Nombrar los PDFs con fecha: `AAAA-MM-DD_descripcion.pdf`.
- Marcar con `[OBSOLETO]` los documentos que queden desactualizados en vez de borrarlos
  (pueden ser útiles para comparar después).
- Datos sensibles: este contenido no debe hacerse público nunca.
