## ¿Qué es este repositorio?

Es el **centro de organización del proyecto**: aquí se guarda y ordena toda la información
(planes de negocio, PDFs, estudios de mercado, finanzas, trámites legales, referencias técnicas…)
y, con el tiempo, servirá también como base para la **página web de la empresa**.

## Cómo usar este repositorio

1. **Todo lo nuevo entra primero en [`00-inbox/`](00-inbox/README.md)**: PDFs, fotos, capturas,
   notas sueltas… sin preocuparse de clasificar en el momento.
2. **Clasificar** cada cierto tiempo (idealmente 1–2 veces por semana) moviendo cada archivo a su carpeta.
3. **Nombrar los archivos** con el patrón: `AAAA-MM-DD_descripcion-breve.ext` (ej. `2026-09-03_estudio-precio-m2-coruna.pdf`).
4. **Notas y documentos propios → Markdown** (`.md`); documentos externos o escaneados → **PDF tal cual**.
5. Marcar el estado de los documentos en desarrollo: `[BORRADOR]`, `[REVISION]`, `[VALIDO]`, `[OBSOLETO]`.
