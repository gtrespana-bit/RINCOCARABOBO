# 07 — Web y marketing

**Propósito:** todo lo relacionado con la **imagen pública** de RemodelaT Coruña:
contenido de la futura página web, textos, imágenes y campañas de captación de clientes.

## Subcarpetas

- [`textos/`](textos/README.md) — Contenido de la web y materiales de venta (borradores).
- [`imagenes/`](imagenes/README.md) — Logotipo, fotos de obras (antes/después), etc.

## Ideas clave para captar clientes de reformas en A Coruña

- La confianza lo es todo: fotos reales de obras, opiniones de clientes, presupuestos claros.
- Canales típicos: **Google (búsquedas "reforma piso A Coruña")**, Google Maps, referencias
  de clientes, inmobiliarias. (Comunidades de propietarios: no se persiguen — D-0004.)
- La web debe servir para generar **contactos/presupuestos**, no solo como escaparate.

## Notas sobre la futura web

- Cuando se desarrolle, el **código** puede vivir en este repositorio (p. ej. en `web/`)
  o en un repositorio aparte. ⚠️ Este repo contiene información interna (finanzas, legal):
  lo público debe separarse bien de lo privado (recomendado: repo aparte para la web).
- Antes de crear la web: definir dominio, estructura de páginas y textos (ver `textos/`).
