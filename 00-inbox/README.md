# 00 — Bandeja de entrada (Inbox)

**Propósito:** punto de entrada de *todo* lo que aún no está clasificado.
PDFs, fotos, capturas de pantalla, notas rápidas, enlaces… aquí se puede "tirar" cualquier cosa
sin pensar.

## Reglas

1. Si el archivo puede esperar a ser clasificado, se deja aquí tal cual.
2. **Vaciar periódicamente** (idealmente cada 1–2 semanas): cada archivo se mueve a su carpeta
   definitiva siguiendo el [índice del README principal](../README.md).
3. Al moverlo, se le pone el nombre según convención: `AAAA-MM-DD_descripcion-breve.ext`.
4. Si algo es urgente o importante (ej. un documento que hay que tramitar), se mueve de inmediato
   y se anota en la carpeta de destino o en el [registro de decisiones](../01-empresa/decisiones/).

## Recordatorios típicos que pueden vivir aquí

- PDFs recibidos por correo sin leer.
- Capturas de obras, materiales o ideas.
- Notas sueltas con ideas para la empresa o la web.
